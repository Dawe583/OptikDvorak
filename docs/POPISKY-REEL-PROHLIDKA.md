## Jak video vyrobit / překreslit

```bash
cd promo-video
npm install                                   # jednorázově
node scripts/make-audio-prohlidka.mjs         # vyrobí music-prohlidka.wav
npx remotion studio                           # náhled a ladění
npx remotion render reel-prohlidka out/reel-prohlidka.mp4          # 4K master (2160×3840)
npx remotion render reel-prohlidka out/reel-prohlidka-1080.mp4 --scale=0.5   # rychlejší 1080×1920 pro IG
```

Kdyby se měnily délky záběrů, uprav i časy v `scripts/make-audio-prohlidka.mjs`
(konstanty `T_DOLLY`, `T_WALL`, `T_PULT`, `T_STUL`, `T_OUT`) — musí sedět
s exportem `CUES` v `src/ReelProhlidka.tsx`.
